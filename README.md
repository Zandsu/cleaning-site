# Лендинг клининговой компании (Astro)

Запуск: `npm install`, затем `npm run dev` (разработка) или `npm run build` → папка `dist/`.

- Контакты, цены, тарифы, рейтинг, тексты, FAQ: `src/data/config.ts`
- Фото до/после и постеры видео: `public/img/` (или пути в `works`/`videos` в config.ts); видео — поле `src`
- Метрика/GA и адрес сайта: скопируйте `.env.example` в `.env`
- Цвета: переменные в начале `src/styles/global.css`
